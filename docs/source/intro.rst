Introduction
============

``pldflow`` provides a Qt-based desktop workflow for pulsed laser deposition experiments.
It combines a parameter-entry form with supporting analysis utilities and a separate raw-data visualizer.

The package is organized around the import namespace ``pld_workflow`` while the published PyPI name is ``pldflow``.

Main components
---------------

- parameter form for PLD growth records
- JSON and HTML export for saved parameter sets
- plume-analysis helper utilities
- standalone raw-data visualization for AFM, XRD scans, and reciprocal-space maps
