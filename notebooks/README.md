# Notebooks

This folder holds notebook-style demos and scratch analysis that are intentionally separate from the three app launchers in `examples/`.

Suggested starting points:

- `01_parameter_recorder_quickstart.ipynb`
- `02_plume_manager_and_metrics.ipynb`
- `03_parameter_trend_analysis.ipynb`
- `04_plume_manager_showcase_dataset.ipynb`

`sample_data/` contains lightweight JSON examples and templates for testing the analysis helpers and generating plume-manager showcase datasets.
